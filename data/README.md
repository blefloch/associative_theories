This folder contains data files that are generated by programs in the
`scripts` directory.  In the following description, ETP refers to the
Equational Theories Project.

- `associative_equations.txt`: gives the 653 equations of order up to 4,
  on an associative binary operation, excluding all tautological
  equations apart from Equation1 `x = x`, in the same order as the ETP;
  this is equivalent to filtering the 4694 magma equational laws to keep
  only those that are right-associated

- `associative_equation_ids.json`: list of 653 ETP ids for the equations
  in the same order as in `associative_equations.txt`

- `associative_equation_classes.json`: list of 122 equivalence classes
  of these 653 equations, each class being given as a list of ETP ids;
  the first entry is a lowest-numbered representative of that class

- `associative_theories.json`: list of 456 JSON objects each describing
  an associative theory, namely an equivalence class of conjunctions of
  the 653 equations (on an associative binary operation), with
  properties
  - `id`, ETP id,
  - `early`, lexicographically-first collection of ETP equations whose
    conjunction describes the equivalence class,
  - `long`, full list of ETP ids implied by the equivalence class,
  - `dual`, the `early` property of the dual associative theory

- `long_classes.json`: list of 456 lists giving, for each of the
  associative theories, its `long` version consisting of the maximal set
  of equations (including associativity) whose conjunction gives that
  equivalence class.  Generated by `../scripts/semigroups-1.py`

- `eq_to_long_class.json`: maps each of the 122 lowest-numbered
  representatives to the list of ETP ids that it (plus associativity)
  implies, namely the `long` description of its equivalence class.
  Generated by `../scripts/semigroups-1.py`

- `explicitly_proven.json`: gives a list of pairs, each consisting of a
  list of premises and a list of goals, such that the conjunction of the
  premises implies each of the goals, and such that once these
  implications are proven (by an equational reasoning, formalized by
  converting a Vampire proof to Lean), all remaining positive
  implications can be deduced by simple logic manipulations
