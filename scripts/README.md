# Scripts used to determine classes and generate Lean code

Several external tools are needed for the following scripts; the paths
to these scripts is hard-coded, they should be in the `scripts`
directory and named `prover9`, `mace4`, `vampire`.  Versions used in
this project: prover9 and mace4 version 2009-11A, and vampire version
4.9 linked with Z3 4.12.3.0

In the description below, ETP id means the 4694 equation numbers
assigned by the Equational Theories Project to magma equations of order
at most 4; we only use the subset of 653 of these that correspond to
right-associated equations, in addition to the equation number 4512 for
the associativity equation itself.  Equivalence classes of conjunctions
of these equations (together with associativity) are described when
possible by their `early` representative, meaning lexicographically
first.

To regenerate all generated data files, run python3 successively on
`semigroups-1.py`, `semigroups-2-organize.py`,
`semigroups-3-minimal.py`,

## Scripts used to find 456 associative theories

- `find_equation_id.py` comes directly from the Equational
  Theories Project https://github.com/teorth/equational_theories/

- `ATP_utils.py` is a collection of tools to call the Prover9 theorem
  prover and Mace4 automated model builder

- `semigroups-1.py` seeks implications between semigroup equations and
  their conjunctions and determines a list of 122 inequivalent equations
  (including the tautological one) and 456 equivalence classes of
  conjunctions thereof, described by their early representative.  The
  output is written to `semigroups_to_rep_out.py` and
  `../data/long_classes.json` and `../data/eq_to_long_class.json`

- `countermodels.py` is generated (if absent) when running
  `semigroups-1.py` and collects countermodels used there

- `countermodels_5.py` provides more countermodels that would be useful
  for some implications at order 5 (currently unused)

- `semigroups_to_rep_out.py` Python module generated by
  `../scripts/semigroups-1.py` and that defines
  - `one_rep_list` list of ETP ids of minimal representatives
  - `multi_rep_list` list of tuples of ETP ids serving as early
    representatives of equivalence classes of conjunctions
  - `one_to_rep` dictionary mapping each of the 4694 ETP ids to the
    minimal representative of associative equation
  - `multi_to_rep` dictionary mapping tuples (consisting of an early
    representative complemented by an additional ETP id) to the
    equivalent early representative when it differs

## Scripts to construct a comprehensive data file

- `semigroups-2-organize.py` extracts from `semigroups_to_rep_out.py`
  several data files that may be useful.  It generates
  `../data/associative_equations.txt` and
  `../data/associative_equation_ids.json` and
  `../data/associative_equation_classes.json` and the main data file
  with all of the available information,
  `../data/associative_theories.json`

- `semigroups-3-minimal.py` produces `../data/explicitly_proven.json`
  which gives the list of implications to be proven using algebraic
  manipulation.  All others can be deduced by graph manipulations
  without knowing what the equation numbers correspond to

## Scripts producing Lean code for the formalization

- `vampire_to_lean.py` module that calls Vampire to produce Lean proofs
  of individual implications, mostly taken from the Equational Theories
  Project `vampire_proofs.py` script

- `generate_conjectures.py`

- `generate_conjunctions.py`

- `generate_implications.py`

- `generate_long_implications.py`

- `generate_models.py` generates the Lean files for all countermodels
  used to disprove implications between associative theories

- `generate_theories.py` produces two Lean files, with the "early" and
  "long" representatives of associative theories

- `generate_equiv.py` produces Lean files with the proof that
  the "early" and "long" representatives of associative theories
  are equivalent
