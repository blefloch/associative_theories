## Commutative semigroups with restricted squares

This conjunction describes commutative semigroups in which multiplication by any square is the same idempotent map `C:M→M`, namely `y◇y◇x = C(x)` for any `x,y` and `C(C(x))=C(x)`.  The image of `C` is a unipotent commutative semigroup.

The free semigroup on some set `Σ` of generators for this law is `( ({0,1}×𝒫(Σ)) ∖ {(0,∅)} ) ⊔ Σ` with the generators `(0,{a})` for `a ∈ Σ`, and with the operation `(0,A) ◇ (0,B) = (0, A ∪ B)` for disjoint subsets, `(0,{a}) ◇ (0,{a}) = a` for equal singletons, `(_,A) ◇ (_,B) = (1, A Δ B)` otherwise; `(_,A) ◇ a = a ◇ (_,A) = (1,A)` and `a ◇ b = (1,∅)`.  Here `𝒫(Σ)` is the set of finite subsets of `Σ` and `Δ` is the symmetric difference operation.
