## Commutative semigroups with equal cubes

This conjunction describes commutative semigroups in which all cubes `x◇x◇x` are equal.

The free semigroup on some set `Σ` of generators for this law is the set of maps `(Σ ⊔ {∞}) → {0,1,2}` whose sum of values is finite, except the zero map, equipped with the operation `(f ◇ g)(a) = f(a) + g(a) mod 3` and `(f ◇ g)(∞)` is equal modulo 2 to `f(∞) + g(∞)` plus the number of `f(a) + g(a) ≥ 3` and vanishes if and only if `f(∞) = g(∞) = 0` and all `f(a) + g(a) < 3`.

This conjunction is equivalent to its dual.
